# Cove Mobile v0.8.2

发布日期：2026-10-17。Android versionCode：15。

## 新增与修复

- **登录与账号记忆**：调整登录、房间、聊天、资料及设置界面；支持记住上次服务器、恢复账号会话，并通过 Android 系统加密保存用户选择记住的账号密码。修复修改邮箱与服务器授权探测互相干扰，以及过期异步结果覆盖当前输入的问题。
- **固定十四天的服务器授权**：按服务器、账号和证书设置恢复有效授权，无需每次重启都输入服务器访问密码。十四天从成功验证时刻计算，重连和自动登录不会续期；授权失效、撤销或密码变更后重新验证，服务器访问密码明文不保存。
- **房间语音包管理**：增加系统文件选择、多文件逐个试听、裁剪上传、原文件保存、分组、排序与收藏；列表、操作及受保护文件均限定在当前房间。本机分组与收藏按服务器、账号和房间分别保存。
- **共享标注与远控**：观看共享时可使用同步标注工具，并可申请控制支持远控的 Windows 共享端；由共享者确认后发送指针、点击、滚轮、按键与文本。手机仅作为远控控制端，不支持手机系统被控制。
- **屏幕共享与诊断**：增加原始尺寸、75% 和 50% 的采集缩放选项，记住缩放及共享音频选择；优先尝试设备与服务器共同支持的硬件 H.264。创建、初始化或运行编码失败时会重新发布兼容编码的共享；运行中回退会重建共享通道，观看端需重新点击观看，语音通话不受影响。媒体诊断显示编码选择、实际编码器及可用的帧率和编码耗时统计。Android 屏幕采集目标保持 30 FPS，观看帧率由共享源、设备和网络决定；未测量真机帧率或耗电收益。

## 安装与兼容说明

下载 Cove-Mobile-0.8.2.apk 后覆盖安装。应用 ID 为 com.cove.mobile，沿用已发布 0.8.1 的签名身份。
支持 ARM64 和 ARMv7，最低 Android 7.0；安装由 Android 系统界面确认。共享应用音频需要 Android 10 及以上，并受被共享应用的录制策略限制。

房间语音包和手机远控需要配套新版服务端。协议 3 与最低连接版本要求保持不变；现有账号、房间和聊天记录保留。历史全局语音包记录及原文件保留，不自动分配到房间；新上传的语音包仅属于当前房间。

更新下载继续使用独立配置的 HTTPS 下载基址，默认留空时使用 GitHub；官方镜像域名为 cove.luxe。应用打开浏览器下载 APK，再由用户确认安装。
