# Cove Mobile v0.8.0

发布日期：2026-10-06。Android versionCode：13。对应桌面客户端及服务端版本：2.0.0。

## 改进与修复

- 保留服务器密码输入、一次性初始化、访问令牌及登录恢复；HTTP、Socket.IO 和同源媒体请求使用手机自身版本 0.8.0 与协议 3。
- 连接前检查分平台最低版本。需要升级时暂停连接；Android 下载更新后验证 APK 大小、SHA-256、应用 ID、版本号及签名，安装由系统界面确认。
- 自动更新继续使用独立配置的 HTTPS 下载基址，默认留空时使用 GitHub。普通更新由用户选择下载；失败可重试，已校验的下载可复用。
- 手机 0.7.0 及更早已发布版本仍通过原有更新弹窗在浏览器中下载本次 APK，无法远程补上自动下载能力。0.8.0 更新清单保持旧版可读取的格式。

## 安装说明

下载 Cove-Mobile-0.8.0.apk 后覆盖安装，应用 ID 和签名保持不变。
正式分发支持 ARM64 和 ARMv7，最低 Android 7.0；不包含 x86 模拟器架构。
