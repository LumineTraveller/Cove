# Cove Mobile v0.8.4

发布日期：2026-10-30。Android versionCode：17。

## 修复与改进

- 移除手机发起屏幕共享和批注的入口与运行接线。观看其他成员共享时，全屏画面使用完整观看区域，远控工具按需展开。
- 改善音量条触控：扩大命中区域，拖动后手指上下偏离轨道仍会持续调整，避免被页面滚动抢走。用户音量继续支持 0–200%。
- 恢复共享屏幕音量和静音控制，普通观看、音频设置及全屏音量浮层同步同一个值。
- 降低语音包播放启动等待：加入语音后优先预备收藏及前排音频，按下时继续预热；准备完成时直接使用原生播放器。未就绪时使用更短的音频缓冲回退，仍由服务器广播确认播放。
- 修复聊天、语音包和音频设置按钮文字偏上、图文折行的问题；移除媒体状态入口及诊断面板接线。

## 安装与兼容

下载 `Cove-Mobile-0.8.4.apk` 覆盖安装。应用 ID 保持 `com.cove.mobile`，沿用已发布版本的签名身份。支持 ARM64 / ARMv7，最低 Android 7.0；安装仍需 Android 系统界面确认。

共享观看、语音及按授权使用的远控保留。语音包预备缓存仅在本机当前会话的应用私有临时目录中存在，退出语音、切换房间或凭据变化时释放；不提前播放未经服务器确认的请求。

更新继续使用独立配置的 HTTPS 下载基址，默认留空时使用 GitHub；官方镜像为 `cove.luxe`。本次只发布手机安装包与更新文件，不替换或重启线上业务服务。

## 验证范围

已完成自动化回归、Android 构建和模拟器界面/原生播放器验证。此前同一模拟器上、缓存已就绪的 10 次播放器启动中位数由 353.5 ms 降至 16.5 ms；该测量是点击处理到播放器报告开始播放，排除真实信令往返和声学出声时间，不能作为真机延迟承诺。

**真实手机验收尚未完成**：本机没有已连接授权的实体手机。真实共享音频链路、扬声器/耳机路由、实际触控体验与端到端声学延迟仍未验证。
