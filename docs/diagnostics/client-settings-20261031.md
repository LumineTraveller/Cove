# 2026-10-31 客户端调整

基于已获用户认可并冻结的性能候选 `894472d`，本轮只处理聊天字号、共享方音量和更新设置。不再调帧率、编码、码率或画质策略；不发布或改线上服务。

## 功能

- 聊天消息与输入固定为历史“小”字号 14px / 21px。旧字号菜单、状态及存储读取已在此前删除，本轮修正遗留的固定 16px；桌面与手机一致，手机保留系统字体缩放。
- 桌面共享方音量回到观看方同一控制位置，调节实际发送的独立屏幕音频增益。零音量或管理员静音不隐藏控件；发送和接收各自保存静音前音量，切源不重建已有音频 producer，停止/离开清理状态。没有新增 Android PCM 发送增益功能。
- 登录页右下角“更新设置”与设置内“检查更新”复用同一更新面板。强制升级提示内也保留设置入口。

## 更新契约

- 更新服务器与登录服务器独立，保存于 Electron `userData/update-settings.json`，进程重启和正常应用升级后保留。没有配置时默认留空，不迁移或猜测登录地址。
- 填写 HTTPS 根地址或路径前缀，例如 `https://updates.example.com/cove`。索引为 `<base>/releases/latest.json`，版本目录为 `<base>/releases/vX.Y.Z/`；安装包、`latest.yml`、旧新 blockmap 必须按现有发布契约提供。
- 保存配置本身不发网络请求。空地址禁止后台启动、定时和强制升级提示的自动检查/下载；手动检查与“GitHub 检查并下载”仍可使用。自动入口在主进程读取当前配置，不能被旧页面快照绕过。
- 有配置时，服务器提供可用新版本即优先采用，不先请求 GitHub。服务器超时、缺文件、清单不合法或下载失败时再惰性回退 GitHub；服务器无更新时也可查 GitHub，防止旧镜像长期遮蔽新版本。
- 地址保存/清空会取消旧发现请求，过期响应不启动新下载；下载、校验和已下载阶段拒绝换源，保留在途任务及缓存。IPC 限主窗口/主 frame并验证参数。
- 保留 StableNsisUpdater 的原生差分 planner、Range、缓存锁、版本基线与 SHA512 验证。可信旧安装器/旧新 blockmap/Range 任一不满足时仍安全全量兜底，并显示回退原因，不能保证每次都差分。
- metadata 请求有大小、时限及跳数限制；下载保持原有语义，允许合法 HTTPS 重定向和 GitHub 签名 URL，拒绝降级与无效资产地址。当前只发布完整 NSIS，明确禁用不使用的 web installer。
- macOS/Linux沿原有更新实现；本轮完整差分和传输守卫的验证范围为 Windows。
