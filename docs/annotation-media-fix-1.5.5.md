# Cove Media Fix 1.5.5 批注更新

基于已验证的 `d415c42e58d90036402f6b7a7343d2b2f0333708`，分支 `fix/annotation-direct-drawing-20261006`。成功版源目录保持原样；检查点 `checkpoint/media-fix-d415c42-20261006`，旧 1.5.4 安装包保存在 `runtime/annotation-update/rollback/`。

## 行为

- 新共享自动采用已保存的“允许批注”开关，默认允许同频道观看者直接绘画，不依赖共享者进入绘画，不需要额外审批。新客户端共享者接管已有会话时统一采用全员许可，保留该会话的开关状态。旧客户端共享者的申请协议仍兼容。
- 管理共享中“批注已开启/已关闭”控制房间批注权限；“在共享屏幕绘画”只控制本地鼠标输入。关掉后撤销绘画，重新共享仍保留关闭偏好；开始绘画不会暗中开启权限。
- Windows 共享者直接在采集显示器或所共享窗口的采集客户区绘画。窗口共享时需先切到被共享窗口。桌面版共享者没有视频预览批注输入层，避免二次映射和双重绘制；观看者继续使用原有视频内容坐标与黑边工具球。
- 原生层提供画笔、光点、橡皮、清空、退出。只在本地绘画期间接管鼠标；Esc、可见退出按钮、Ctrl+Alt+Shift+A、失焦、关闭批注、分享结束、源窗口关闭、渲染进程异常均释放输入。紧急快捷键注册失败时拒绝进入绘画。
- 原生窗口仍启用捕获排除（`WDA_EXCLUDEFROMCAPTURE=0x11`），无需把覆盖层再采进视频。共享者和观看者经同一批注状态绘制；层本身没有网络连接、OS 输入注入或独立捕获。
- 已授权远控的视频容器使用 8×8 px SVG，中心白点直径约 3.2 px、细暗边，热点 `(4,4)`。退出区域使用原样式；停止、撤销、断线和批注模式取消 controlling 状态。没有改系统光标。
