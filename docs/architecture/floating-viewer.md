# 桌面观看置顶小窗

## 目标与边界

基线为 `3435e96c`，实现分支为 `codex/desktop-floating-viewer`。仅增加桌面观看共享时的呈现方式；手机、服务端协议、编码、码率、采集与观看恢复策略保持不变。已有验收包和 Library 副本不覆盖。

## 实现计划

1. 用现有 Electron 44 在隔离测试窗口确认原生视频 Picture-in-Picture 能力、进入/退出事件、主窗口最小化与窗口关闭行为。
2. 优先将正在播放的同一个静音 `HTMLVideoElement` 交给原生画中画。它继续引用原来的远程 `MediaStream`；不跨 IPC 序列化流，不创建第二个 Consumer、播放器音频或编码链。若实际平台不支持，明确提示且保留原观看。
3. 呈现控制器只拥有小窗请求、事件监听及取消代次，不拥有媒体轨道或连接。重复进入合并；异步迟到不能重新打开已取消的观看。退出小窗返回主窗口，不调用停止观看/退出语音。
4. 原生小窗负责置顶、拖动、等比例缩放及显示器工作区约束。Cove 提供清晰的进入/返回操作；首版小窗只观看，避免远控与批注坐标跨窗口映射。真正停止观看、共享结束、换流/切换共享、离房及应用退出均结束对应小窗。
5. 先补取消、重复请求、迟到响应和媒体所有权回归；再跑真实 Electron 视频/窗口测试及受影响全量检查。冻结新提交后生成独立命名的 Windows 验收 ZIP，复用原 Android APK。

## 验证约束

实测 Electron 44.0.0 / Chromium 152 支持视频原生画中画，默认后台节流开启时主窗口最小化仍持续呈现帧。原生窗口为独立置顶窗口；拖动和窗口管理器的等比例缩放已验证。`MediaStream` 不提供暂停操作，因此原生关闭只退出小窗。原生“返回到标签页”不会自行还原最小化的 Electron 窗口，Cove 在用户退出事件后通过现有 `coveWindow.focus()` 还原、显示和聚焦主窗口。

显式停止观看、换流、共享结束和卸载会主动退出画中画，因为仅移除视频或结束轨道不会关闭原生窗口。自动清理不抢主窗口焦点，不自动重新打开小窗。ICE 恢复复用同一 `MediaStream` 时小窗保持；换流后用户可再次点击进入。全屏和共享操作在小窗期间禁用；进入前需先退出远控或批注，返回后不会自动申请权限。

平台依据：[视频画中画 API](https://developer.mozilla.org/en-US/docs/Web/API/Picture-in-Picture_API)、[Electron WebContents](https://www.electronjs.org/docs/latest/api/web-contents)。显示器物理拔插尚未执行，窗口工作区约束由 Chromium 原生实现负责。

自动验证使用合成画面和本机隔离进程，不读取个人屏幕/麦克风或正式数据。窗口状态、媒体对象/音频路数与画面继续播放分开验证；实测结果与未验证范围会记录到交付说明。原生画中画能力必须以实际 Electron 探测为准，不能以普通 Chromium 的支持情况代替。
