## 范围与回滚点

本轮从正式发布源码 `e31362ce07b316f15265daf6796730d947390b76` 开始，
保留本地分支 `codex/rollback-2.1.1-e31362c`，在
`codex/client-improvements-after-2.1.1` 分模块实现。
正式版本号、更新清单、发布标签和线上服务不在本轮改动范围内。
只生成独立候选产物，不自动安装或触发正式更新。

## 模块及验证重点

| 模块 | 预期行为 | 验证边界 |
| --- | --- | --- |
| Windows 更新 | 保留已安装版本基线，差分前验证身份，失败明确说明并保留完整下载与校验 | 旧缓存迁移、下载/安装并发、基线变化、Range/重定向与最终重建校验分别验证；网络失败不能保证消失 |
| Android 更新 | 应用内下载、进度、取消/重试、成功包复用；校验后仅请求系统安装界面 | 包大小/哈希/版本/包名/签名，权限拒绝、空间不足、过期回调、中断和缓存复验；不静默安装 |
| 共享性能 | 分别记录源、采集、编码、发送、接收解码与呈现，针对共同路径优化 | 动态源、相同条件的修改前后比较；源刷新率与实际媒体帧分开，不用重复帧充数 |
| 个人语音包顺序 | 共享内容保留，个人拖拽不再改房间顺序 | 首次旧顺序迁移、增删内容、旧客户端广播、账号/服务器/房间隔离与桌面/手机交互 |
| 聊天字体 | 移除调整入口及对应状态/持久化，保留固定默认值和系统可访问性 | 两端组件、类型检查和无残留入口 |
| 采集设置 | 兼容观看开关移入原音频设备栏目，栏目改名 | 唯一开关、原语义及生效时机、两端设置交互 |

## 测试与产物记录

各模块先运行相关基线和回归；全部修改完成后运行共享包构建、桌面/手机类型检查、
自动回归及可用的原生构建。桌面高帧率测量期间避免并行大规模编译，记录测量条件。
测试数据、浏览器 profile、缓存与 SFU 进程均隔离，保留正式更新缓存作为证据。

Windows 候选使用独立目录和数据目录；Android 候选使用独立应用标识，
不能假定可覆盖正式应用，不能放宽更新包身份校验来方便测试。
最终提交、实际测试结果、产物路径/校验和及未验证项目在冻结时补齐。

## 已知调查边界

- 历史 Gitee 迁移逻辑删除根安装基线的行为有代码及历史日志依据。
  本次 2.1.0 → 2.1.1 的直接失败为根 `installer.exe` 缺失，具体删除者尚无证据。
- 历史差分重建 SHA512 不匹配有日志依据；缺少当时完整缓存与传输记录，
  不把某个猜测写成全部失败的共同根因。
- 降低编码输出分辨率不等于降低桌面捕获源分辨率，也不保证提高源刷新率。
- 自动测试、真实本机浏览器/媒体测试、真实 Android 与用户设备体验必须分开报告。

## 统一验收与回滚

冻结后以本文件所列最终产物为准，旧正式包和旧候选包保留。
退出候选客户端/测试服务端即可回到正式应用；不迁移或替换正式数据。
源码可切回回滚分支，不能用强制覆盖方式清除用户后续修改。
