# Cove Mobile v0.7.0

发布日期：2026-09-28。Android versionCode：12。

## 新增与修复

- 新增手机屏幕共享，可选择是否同时共享应用播放音频；屏幕视频使用 AV1，不支持 AV1 的设备或服务器会明确提示，不回退到 H.264。共享音频采集需要 Android 10 及以上，并受应用录制策略限制。
- 修复手机麦克风降噪链路的失真问题，重新提供 RNNoise 选项；默认降噪模式改为系统降噪，每次冷启动恢复默认值。
- 调整 Android 原生音频处理与 React Native 模块构建/初始化路径，避免原生处理配置导致应用启动即闪退。
- 新增独立的 HTTPS 更新下载地址配置。默认留空时不访问预设服务器地址；启动更新检查仍可使用 GitHub，配置地址后才会同时检查对应下载服务器。
- 改进登录表单在软键盘弹出时的可视区域处理。

## 安装说明

下载 `Cove-Mobile-0.7.0.apk` 后覆盖安装。应用 ID 与签名保持不变。
正式分发包支持 ARM64 与 ARMv7，最低 Android 7.0；不包含 x86 模拟器架构。
