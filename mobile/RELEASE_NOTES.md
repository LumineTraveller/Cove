# Cove Mobile v0.6.0

发布日期：2026-09-20。Android versionCode：10。配套桌面端及服务端：1.4.0。

## 新增与修复

- 支持识别服务器访问安全状态，并完成服务器密码解锁或首次初始化。
- 服务器密码只用于换取当前进程内的短期访问令牌，不写入本地存储。
- 未初始化、令牌过期或服务器密码轮换时自动返回解锁界面并显示原因。
- 服务器历史记录支持 DNS/IP 别名合并，同时区分不同端口和路径。
- 语音包、聊天图片和 Socket.IO 请求支持服务器访问令牌。
- 公网安全服务器要求 HTTPS/WSS，并保留 Android 证书例外的显式开关。

## 安装说明

下载 `Cove-Mobile-0.6.0.apk` 后覆盖安装。沿用原应用 ID 与签名，不需卸载旧版。
正式分发包支持 ARM64 与 ARMv7 手机，最低 Android 7.0；不包含 x86 模拟器架构。
请先将服务器更新至 1.4.0，并在服务器访问门禁仍关闭时完成客户端升级；更新手机端不会自动更新云端服务端。
