# Cove Mobile v0.5.2

发布日期：2026-09-01。Android versionCode：9。配套桌面端及服务端：0.10.2。

## 新增与修复

- 支持创建房间，选择人数上限或不限人数，并设置可选密码。
- 房主可修改人数上限、更换或取消密码；调整不会踢出现有成员。
- 入房支持密码验证、满员提示及重试；成功进入后才能读取密码房间的聊天记录。
- 同账号后登录者挤下旧端，旧端退出语音和房间并停止自动重连；清除失效凭据但保留地址和邮箱。
- 语音断线保留 7.5 秒恢复窗口，窗口内成员继续占用房间名额。
- 超时或媒体通道失败后正确清理状态，可直接重新加入语音，无需手动重连服务器。
- 修复迟到的入房或麦克风请求在退出后恢复旧状态的问题。

## 安装说明

下载 `Cove-Mobile-0.5.2.apk` 后覆盖安装。沿用原应用 ID 与签名，不需卸载旧版。
正式分发包支持 ARM64 与 ARMv7 手机，最低 Android 7.0；不包含 x86 模拟器架构。
请先将服务器更新至 0.10.2；更新手机端不会自动更新云端服务端。
