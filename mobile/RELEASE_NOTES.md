# Cove Mobile v0.5.0

发布日期：2026-08-30。Android versionCode：7。桌面端版本保持 0.9.0。

## 新增与改进

- 新增邮箱格式校验、账号注册和密码登录，账号 ID 由服务器唯一分配并保存。
- 新增手机端聊天区，语音包入口收缩为顶部按钮；移除手机端语音包排序操作。
- 成员资料页显示实时麦克风状态；点击成员头像可独立调节该成员音量，支持 0%–200%。
- 共享屏幕附带音频和独立应用音频均支持横向拖动调节音量。
- 共享屏幕音量按钮支持静音/取消静音，取消静音会恢复静音前音量。
- 优化手机端状态栏和安全区域适配，避免内容顶到系统状态栏。

## 安装说明

下载 `Cove-Mobile-0.5.0.apk` 后覆盖安装。沿用原应用 ID 与签名，不需卸载旧版。
正式分发包支持 ARM64 与 ARMv7 手机，最低 Android 7.0；不包含 x86 模拟器架构。
若系统要求，请为用于下载 APK 的浏览器开启“允许安装未知应用”，仅安装来自本项目官方发布页的 APK。
